# Squishy style pictures

One picture per squishy style in the "Squishy showdown" part of the questionnaire. The app shows them on
the bracket cards, on the winner screen and in Santa's file.

**To replace a picture, overwrite the file with the same name. No code changes needed.** If you'd rather
use PNG, JPG or WebP (e.g. images you generate yourself), save it here and change that style's `image`
path in `SQUISHY_STYLES` in `packages/core/src/questionnaire.ts` (one line each). Square pictures work
best: they show at about 140 px on the cards and up to 180 px on the winner screen.
